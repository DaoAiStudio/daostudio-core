# DaoStudio.Engine

Implementations use namespace `DaoStudio.Engine` and the existing locked abstractions.

- `TagMasker`: non-backtracking extraction with independent VAR/TAG/NUM counters. Line endings and literal `\n` are TAGs. Repeated placeholders receive separate tokens. Existing canonical-looking source tokens are escaped as VARs; unmasking is a single pass. Standalone numbers use Unicode word boundaries, so digits embedded in words/CJK terms are preserved. Integrity permits token reordering but rejects missing, duplicated, renamed or additional canonical tokens.
- `StringNormalizer`: NFC, horizontal whitespace collapse, CRLF/CR to LF, outer whitespace trim. Does not lowercase or remove meaningful line breaks. Hashing is UTF-8 SHA-256 lowercase hex.
- `L0MemoryCache(maxEntries)`: bounded FIFO with concurrent reads and serialized writes. Updating an existing entry preserves its insertion order.
- `L1SqliteCache(databasePath, encryptionKey)`: persistent connection and prepared commands, WAL/NORMAL, serialized access per instance, SQLite busy timeout for independent instances. Payload layout is 12-byte random nonce, 16-byte authentication tag, ciphertext. AES-256-GCM binds the complete cache key as associated data; cache keys themselves are not encrypted. Default random session key works within the process only. Pass the same private 32-byte key to reuse a database across process restarts. Wrong keys or tampering raise a cryptographic exception. Dispose/DisposeAsync close the connection. SQLite I/O is synchronous, as is Microsoft.Data.Sqlite; cancellation is checked before each operation, not during native I/O. A sub-millisecond warm-hit mean is tested, not a hard real-time guarantee under contention or arbitrary storage hardware.
- `TieredTranslationCache(l0, l1)`: write-through and promotion on L1 hit; dependencies are caller-owned. Access through this facade is serialized to prevent stale promotions. Avoid independently mutating its underlying caches when coherence is required.
- `GlossaryMatcher`: loads the repository's JSON array; matches source terms ordinally, checks forbidden literals case-insensitively for matching entries, and counts Unicode scalar values in translated text. DTO MaxChars is shared across languages. The strictest matched limit applies to the whole output unless overridden.
- Studio parsers accept .json/.csv/.txt case-insensitively and strip a leading UTF-8 BOM. Strings preserve Unicode; file callers should use UTF-8. JSON accepts flat string dictionaries or DTO arrays and exports DTO arrays to retain metadata. CSV accepts two-column key/text data (optional header) and exports six-column DTO rows with RFC-style escaping, including embedded line breaks. In the six-column schema, translatedText and context cells contain JSON nullable strings to distinguish null from empty. TXT uses the first `=` as delimiter, preserves blank lines, exports translated text when present, and canonicalizes line endings to LF with a trailing newline. TXT has no review metadata representation and rejects unrepresentable multiline values or ambiguous plain lines containing `=`. Round-trip guarantees concern content/segments, not original JSON/CSV layout or TXT line-ending bytes.

## Offline validation

Run the requested restore using the local NuGet cache and tests with shared compilation disabled. If the sandbox denies access to the profile's NuGet.Config, use `tests/DaoStudio.Engine.Tests/NuGet.Config`, set APPDATA for that command to `tests/DaoStudio.Engine.Tests/obj/offline-appdata`, and disable NuGetAudit. This does not require network access or editing the user's profile.
